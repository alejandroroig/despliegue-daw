es.escaparate.almacenamiento

Inicio · Paquetes · Informes

Abstracciones e implementaciones para almacenar imágenes de productos. El catálogo depende de `AlmacenamientoImagenes` y no del soporte físico concreto. Las implementaciones disponibles son filesystem —válido también para volúmenes o EFS montado— y Amazon S3.
