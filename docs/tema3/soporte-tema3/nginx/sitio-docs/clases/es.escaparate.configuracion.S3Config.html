es.escaparate.configuracion.S3Config

Crea el cliente de Amazon S3 únicamente cuando el almacenamiento activo es S3. No se configuran credenciales ni región obligatoria en código. Por defecto, el AWS SDK for Java utiliza sus cadenas estándar de proveedores para resolver ambas cosas. En desarrollo local esto permite usar el perfil activo de `~/.aws/credentials` y `~/.aws/config`; en AWS permite evolucionar a credenciales de contenedor o roles de instancia sin modificar la aplicación. /
