es.escaparate.configuracion.CorsConfig

Configura CORS para permitir que un frontend servido desde otro origen consuma la API REST de Escaparate. Los orígenes se reciben como una lista separada por comas mediante `APP_CORS_ALLOWED_ORIGINS`. No se habilitan credenciales porque la aplicación no utiliza sesiones ni autenticación de usuario. /
