es.escaparate.almacenamiento.S3Storage

Implementación de {@link AlmacenamientoImagenes} que guarda los objetos en Amazon S3. El bucket permanece privado: el frontend continúa solicitando las imágenes a la API de Escaparate y esta implementación recupera los bytes desde S3. La base de datos conserva una clave neutral y no una URL física del objeto. /
