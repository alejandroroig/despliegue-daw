Documentación técnica del código y material de calidad del build

Documentación del código

Referencia estática preparada a partir del código de la distribución final de Escaparate utilizada en las prácticas.

Ver índice de paquetes

es.escaparate

Aplicación didáctica Escaparate. El proyecto se utiliza para practicar empaquetado, despliegue, balanceo, observabilidad básica y escenarios de nube sin añadir complejidad funcional innecesaria.

es.escaparate.almacenamiento

Abstracciones e implementaciones para almacenar imágenes de productos. El catálogo depende de `AlmacenamientoImagenes` y no del soporte físico concreto. Las implementaciones disponibles son filesystem —válido también para volúmenes o EFS montado— y Amazon S3.

es.escaparate.api

Componentes transversales de la API HTTP, como el tratamiento uniforme de errores.

es.escaparate.configuracion

Configuración transversal de la aplicación, independiente de la lógica de negocio.

es.escaparate.infraestructura

Endpoints técnicos orientados al despliegue. Incluye identidad de instancia, liveness, readiness y generación de carga sintética para hacer visibles balanceo, probes y escalado.

es.escaparate.infraestructura.dto

Respuestas de los endpoints técnicos de despliegue.

es.escaparate.producto

Catálogo de productos de Escaparate. Contiene el modelo persistente, acceso a datos, lógica de aplicación y endpoints REST del catálogo.

es.escaparate.producto.dto

Objetos de respuesta HTTP del catálogo de productos.
