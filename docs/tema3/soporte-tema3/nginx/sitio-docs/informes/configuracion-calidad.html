Validación prevista por Maven

El pom.xml de Escaparate configura:

  • JaCoCo 0.8.15 para generar el informe de cobertura durante verify.
  • Una puerta mínima del 60 % de líneas cubiertas.
  • maven-javadoc-plugin 3.12.0 para generar documentación durante verify.
./mvnw clean verify

En un equipo con las dependencias Maven disponibles, ese comando genera los informes reales de ejecución y cobertura. Este ZIP se entrega ya preparado para que la sesión de Nginx no dependa de repetir el build.
